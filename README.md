นี่คือโปรเจกต์ Portfolio ส่วนตัวของผม สร้างขึ้นเพื่อรวบรวมผลงาน, บอกเล่าเกี่ยวกับประสบการณ์ และทักษะการพัฒนาซอฟต์แวร์ของผม โดยใช้ Nuxt.js เป็นเฟรมเวิร์กหลักในการพัฒนา

## ✨ ฟีเจอร์เด่น (Key Features)

*   **Project Showcase:** หน้าแสดงรายละเอียดโปรเจกต์ต่างๆ ที่เคยทำ
*   **Responsive Design:** ออกแบบให้รองรับการแสดงผลบนทุกอุปกรณ์ (Desktop, Tablet, Mobile)
*   **About Me & Skills:** ส่วนแนะนำตัวและแสดงทักษะความสามารถ
*   **Contact Form:** แบบฟอร์มสำหรับติดต่อเพื่อให้ผู้ที่สนใจสามารถติดต่อได้ง่าย
*   **Multi-language Support (i18n):** รองรับการแสดงผลหลายภาษา (เช่น ไทย/อังกฤษ)

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

*   **Framework:** [Nuxt.js 3](https://nuxt.com/)
*   **Language:** [TypeScript](https://www.typescriptlang.org/)
*   **UI/Styling:** [Tailwind CSS](https://tailwindcss.com/) 
*   **Internationalization:** [@nuxtjs/i18n](https://i18n.nuxtjs.org/)
*   **Deployment:** [Vercel](https://vercel.com/)

## 🚀 เริ่มต้นใช้งาน (Getting Started)

ทำตามขั้นตอนต่อไปนี้เพื่อรันโปรเจกต์บนเครื่องของคุณ

### สิ่งที่ต้องมี (Prerequisites)

*   [Node.js](https://nodejs.org/) (แนะนำเวอร์ชัน 18.x ขึ้นไป)
*   Package Manager ที่คุณเลือก (npm, yarn, หรือ pnpm)

### การติดตั้ง (Installation)

1.  Clone a repository:
    ```bash
    git clone <https://github.com/your-username/your-repo.git>
    ```

2.  เข้าไปในโฟลเดอร์โปรเจกต์:
    ```bash
    cd your-repo
    ```

3.  ติดตั้ง Dependencies:
    ```bash
    # หากใช้ npm
    npm install

    # หากใช้ yarn
    yarn install

    # หากใช้ pnpm
    pnpm install
    ```


### รันในโหมด Development

```bash
npm run dev
```
